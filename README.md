# Friendly Steps Trainer

A simple external trainer for **Friendly Steps**.

Friendly Steps Trainer provides optional gameplay enhancements and quality-of-life features for players who want to customize their single-player experience.

> ⚠️ **Disclaimer:** This project is not affiliated with, endorsed by, or sponsored by the developers or publishers of Friendly Steps.

## ✨ Features

* 🎮 Gameplay modifications
* ⚙️ Easy-to-use trainer interface
* 🔘 Toggle features on and off
* 🖥️ Lightweight external application
* 🔄 Designed for the current version of Friendly Steps

## 📋 Requirements

* Windows 10 / 11
* Friendly Steps installed through Steam
* Administrator privileges may be required depending on the enabled features

## 🚀 Usage

1. Launch **Friendly Steps** through Steam.
2. Run **Friendly Steps Trainer**.
3. Select the features you want to enable.
4. Return to the game and enjoy.

For the best experience, start the game before activating the trainer.

## 🛠️ Building

Clone the repository:

```bash
git clone <repository-url>
cd FriendlySteps-Trainer
```

Open the project in your preferred IDE and build it using the appropriate configuration.

### Release Build

Build the project in **Release** configuration and run the resulting executable.

## 🔧 Compatibility

The trainer is version-dependent.

Game updates may change memory addresses, offsets, or other internal structures and can cause some features to stop working.

If a new version of Friendly Steps is released, check the compatibility before using the trainer.

## 🐛 Issues

If something doesn't work:

1. Make sure you are running the latest version of the trainer.
2. Make sure Friendly Steps is updated.
3. Restart both the game and the trainer.
4. Check the existing GitHub issues.
5. Open a new issue with:

   * Game version
   * Trainer version
   * Windows version
   * Feature that is not working
   * Relevant logs or screenshots
